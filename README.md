# КП «Тихое» — готовая демоверсия для VPS

Готовый standalone-пакет для Ubuntu 24.04 x86_64, IP 90.156.135.117.
Сборка на VPS не требуется.

[Исходный код](https://github.com/newo0/vrevo/tree/270a665babbace97c30294d74f2a78adb483b1f0) · [Описание установки](https://github.com/newo0/vrevo/blob/270a665babbace97c30294d74f2a78adb483b1f0/deploy/README.md)

`install-demo.sh` устанавливает пакет с проверкой SHA-256. Перед запуском задайте
`TIKHOE_RELEASE_REF` равным полному SHA коммита этой ветки, из которого скачан установщик.

После установки откройте http://90.156.135.117 с логином `preview` и паролем,
который установщик выведет в терминале VPS. Пакет ещё нужно запустить на сервере.
