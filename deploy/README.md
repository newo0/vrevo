# Установка демоверсии КП «Тихое» на VPS

Подготовлено для предоставленного VPS: Ubuntu 24.04, x86_64, IP `90.156.135.117`.
Сборка выполняется в рабочей среде Codex. На VPS передаётся готовый Next.js standalone-пакет;
на сервере с 1 ГБ памяти сборка и установка npm-зависимостей не нужны.

Ветка `deploy/demo` содержит готовый архив, его SHA-256 и установщик.
Для установки нужен доступ VPS к raw.githubusercontent.com и репозиториям Ubuntu.
Скачивание из GitHub без авторизации требует открытого репозитория.

Запускать `install-demo.sh` под root, задав `TIKHOE_RELEASE_REF` равным полному
идентификатору коммита ветки `deploy/demo`, из которого скачан установщик.
Установщик проверяет контрольную сумму пакета и официальный SHA-256 Node.js.
Неизменённый официальный архив Node.js сохранён в той же ветке GitHub: прямой
доступ VPS к nodejs.org не требуется. Архив проверен по SHASUMS256.txt с nodejs.org
перед загрузкой в GitHub; эта сумма также зафиксирована внутри установщика.
Он предназначен для первоначальной установки; повторный запуск после успешной установки
показывает адрес и существующий пароль, не заменяя базу данных.

Будут созданы:

- `/opt/tikhoe-demo` — готовое приложение и отдельный Node.js 24.19.0.
- `/var/lib/tikhoe-demo` — постоянная SQLite-база и папка загрузок.
- `/etc/tikhoe-demo/app.env` — настройки только деморежима.
- `/etc/tikhoe-demo/preview-password` — случайный пароль просмотра (доступ только root).
- `tikhoe-demo.service` — автозапуск от отдельного системного пользователя.
- Дополнительный сайт nginx; существующие сайты и настройки SSH не удаляются.

Просмотр: `http://90.156.135.117`, логин `preview`; пароль выводится после успешной установки.
Это временный HTTP-просмотр с отдельным паролем, не пароль администратора или VPS.
Доступ к управлению и входу администратора через nginx закрыт. Письма не отправляются.
В исходной базе пакета нет учётных записей, сессий, заявок или загруженных пользователем файлов.

Установщик выполняет локальные проверки HTTP и базы на VPS. Они не подтверждают доступность
из интернета: внешние правила сети Masterhost также должны разрешать TCP 80.

Диагностика:

```sh
systemctl status tikhoe-demo nginx --no-pager
journalctl -u tikhoe-demo -n 40 --no-pager
```

Для публичного запуска отдельно нужны домен, HTTPS, администратор, SMTP и выполнение
проверок публикации из основного README. Одной смены SITE_MODE недостаточно.

Проверено до передачи: сборка и lint, отдельный запуск standalone, 146 участков / 10 проданных,
все фотографии, мобильная ширина 390 px и тестовая заявка. Конфигурация nginx проверена
в контейнере: 401 без пароля, 200 с паролем, 403 для управления и заголовок noindex.
Установщик проверен `bash -n`; полный запуск на VPS из этой рабочей среды не выполнен
из-за недоступности SSH.
