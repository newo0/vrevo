# Вревские дачи — итоговый комплект для Codex

Открой TZ_Codex_Vrevo.md и реализуй сайт по этому заданию. Основной предмет продажи — участки без подряда; цена предложения от 90 000 рублей за сотку.

Состав комплекта:

- TZ_Codex_Vrevo.md — полное ТЗ после интервью.
- project_data.json — подтвержденные ответы заказчика и настройки первоначального наполнения.
- sources/genplan.pdf — исходный план всего поселка. Перерисовать реальные контуры в SVG, сохранить дороги и инфраструктуру. Проверить ошибки исходной нумерации.
- photos/ — 20 подобранных оригинальных фотографий, включая 3 вида с высоты.
- photo_sources.json — источник, автор, место, условия использования и назначение каждого изображения.
- PHOTO_INDEX.md — список номеров и файлов.
- Vrevo_Photo_Selection.pdf — обзор подборки с миниатюрами.
- PHOTO_CREDITS.md — читаемые сведения об атрибуции и применении фотографий.

Проданы участки 68–72 и 99–103, всего 10. Не окрашивать другие участки как проданные по приблизительному желтому контуру старой фотографии. Статусы и цены должны редактироваться через обязательную закрытую админку и сохраняться в постоянной базе данных.

Заявки направляются на обе почты из project_data.json. Получатели — серверная настройка, а не автоматически публикуемые контактные адреса. Публичный телефон — +7 911 777-44-86, Владислав. Для тестирования почтовой интеграции использовать тестовый приемник без рассылки фиктивных обращений.

Не выдавать изображения соседнего Череменецкого озера за Врево. Применение фотографий и ограничения указаны отдельно для каждого файла. Фотография Врево из районной газеты — для закрытого макета до подтверждения прав; снимки заказника из Wikimedia Commons допускают использование по CC BY-SA 4.0 с выполнением ее условий.

Название «Вревские дачи» утверждено заказчиком 20 октября 2026 года. Использовать его в оформлении сайта, метаданных и уведомлениях; значение хранить в редактируемой конфигурации.

В расширенную подборку входят Врево, Череменецкое озеро и леса Шалово-Перечицкого заказника. На снимках с чужой застройкой нельзя обозначать территорию проекта. Точные роли и география указаны в разделе 12 ТЗ и у каждого изображения.
